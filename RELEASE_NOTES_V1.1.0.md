# 🚀 CinemaHub v1.1.0 — OTA Updates & Custom App Icon

CinemaHub **v1.1.0** brings essential ecosystem upgrades: our custom brand identity icon and seamless Over-The-Air (OTA) updates!

---

### 🌟 What's New in v1.1.0

#### 📲 Over-The-Air (OTA) In-App Updates
* **Automatic Update Checks:** On startup, CinemaHub checks GitHub for new releases in the background without slowing down app launch.
* **In-App Update Modal:** If an update is detected, a cinematic dialog displays the latest version, changelog, and a one-tap **"Update Now"** button.
* **Direct APK Download & Install:** Tapping "Update Now" downloads the release APK directly to your device and opens Android's package installer for immediate updating.
* **Manual Check in Settings:** Added a **"Check for Updates"** tile in **Settings > About & Updates** with live version display (`v1.1.0`).

#### 🎨 CinemaHub Brand App Icon
* Replaced the default Flutter logo with CinemaHub’s custom brand badge — a golden-accented film reel with play icon on a cinematic dark canvas.
* Multi-density adaptive rendering across `mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, and `xxxhdpi` devices.

---

### 🎬 All Core CinemaHub Features Included
* **Private Community Access:** Google Sign-In & Email Authentication with real-time live admin approval synchronization.
* **TMDB Catalogue:** High-res trending/popular movies and TV shows, instant debounced search, and season/episode pickers.
* **Stremio Streaming:** Built-in hardware-accelerated playback + one-tap external player launch (VLC, MX Player).
* **My List Watchlist:** Save favorite movies and series locally.
